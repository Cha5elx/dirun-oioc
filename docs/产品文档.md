# DiRun OIOC 产品文档

## 一、产品概述

### 1.1 产品定位

DiRun OIOC 是一个**中间件同步服务**，连接**有赞商城**与**第三方一物一码系统**，实现库存、订单、防伪码的自动双向同步。

```
有赞商城 ←── Webhook/API ──→ 本服务 ←── Webhook/API ──→ 第三方一物一码系统
  (销售渠道)                   (数据桥梁)                   (溯源管理)
```

### 1.2 核心价值

| 价值 | 说明 |
|------|------|
| **自动化** | 入库自动加库存、出库自动发货扣库存，全程无需人工操作 |
| **防伪溯源** | 每件商品绑定唯一防伪码，消费者可扫码验真伪、查来源 |
| **零差错** | 幂等性保护 + 失败重试队列，确保数据不丢不重 |
| **可观测** | 同步日志、重试队列统计、健康检查，运维状态一目了然 |

### 1.3 用户角色

| 角色 | 操作入口 | 职责 |
|------|---------|------|
| **仓库管理员** | 第三方一物一码系统 | 扫码入库、扫码出库、扫码退货 |
| **商家运营** | 有赞商家后台 + 本服务管理后台 | 查看订单、管理商品映射、监控同步状态 |
| **消费者** | 微信/支付宝扫码 | 查询防伪码、验真伪、看溯源 |
| **系统管理员** | 本服务管理后台 | 用户管理、日志管理、系统配置 |

## 二、功能清单

### 2.1 核心业务流程

| 流程 | 触发方 | 说明 | 状态 |
|------|--------|------|------|
| **商品采购入库** | OIOC Webhook | 仓库扫码入库 → OIOC推送 → 有赞自动加库存 | ✅ |
| **销售发货** | 有赞 Webhook → OIOC Webhook | 用户下单 → 创建出库单 → 扫码发货 → 有赞自动发货+扣库存+写防伪码 | ✅ |
| **退货退款** | 有赞 Webhook → OIOC Webhook | 用户退货 → 创建退货单 → 扫码退货 → 有赞自动恢复库存 | ✅ |

### 2.2 管理后台功能

| 页面 | 功能 | 权限 |
|------|------|------|
| **数据仪表盘** | 今日订单/入库/出库/退货统计 | operator |
| **同步日志** | 查看所有同步操作记录，支持按类型/状态/时间筛选 | operator |
| **有赞订单** | 查看有赞订单列表和详情 | operator |
| **防伪码查询** | 输入防伪码查询商品溯源信息 | operator |
| **用户管理** | 创建/编辑/删除用户，角色分配 | admin |
| **产品映射** | 管理有赞商品SKU与OIOC产品编码的映射关系 (API) | admin |

### 2.3 系统保障机制

| 机制 | 说明 |
|------|------|
| **幂等性保护** | 基于业务键 + 数据指纹的重复请求检测，防止重复入库/发货 |
| **失败重试队列** | API 调用失败自动入队，指数退避重试（30s → 60s → 120s），最多3次 |
| **签名验证** | Webhook 接收时验证 HMAC-SHA256 签名，防止伪造请求 |
| **速率限制** | 普通 API 和 Webhook 独立限流，防止滥用 |
| **日志清理** | 定时清理过期日志（默认保留30天/10000条），自动 VACUUM 数据库 |
| **Token 管理** | OIOC Token 自动缓存和刷新，有赞 Token 免登续期 |
| **Dry Run 模式** | `YOUZAN_DRY_RUN=true` 时跳过有赞 API 真实调用，安全测试 |

## 三、系统架构

### 3.1 技术栈

| 层 | 技术 |
|----|------|
| **后端运行时** | Node.js 18+, Koa 3.x |
| **数据库** | SQLite 3 (Sequelize ORM, WAL 模式) |
| **前端** | Vue 3 + Element Plus + Pinia + Vue Router |
| **日志** | Winston (文件 + 控制台) |
| **进程管理** | PM2 (生产环境) |
| **反向代理** | Nginx |

### 3.3 数据流图

```
流程1 — 入库:
  OIOC 系统 ─POST /webhook/oioc {type:"inbound"}─→ webhook.js
    → sync.handleInbound()
      → oioc.login()
      → oioc.createInboundOrder()     (在OIOC创建入库单)
      → youzan.addStock()              (有赞加库存)
      → syncLog.create()               (记录日志)

流程2 — 发货:
  有赞 ─POST /webhook/youzan {type:"trade_TradePaid"}─→ webhook.js
    → sync.handleOrderCreated()
      → youzan.getOrder()             (获取订单详情)
      → oioc.login()
      → oioc.createOutboundOrder()    (在OIOC创建出库单)
      → syncLog.create()

  OIOC ─POST /webhook/oioc {type:"outbound"}─→ webhook.js
    → sync.handleOutbound()
      → youzan.subtractStock()        (有赞扣库存)
      → youzan.shipOrder()            (有赞标记发货)
      → youzan.updateOrderRemark()    (写入防伪码到备注)
      → syncLog.create()

流程3 — 退货:
  有赞 ─POST /webhook/youzan {type:"trade_TradeRefundCreated"}─→ webhook.js
    → sync.handleRefund()
      → oioc.createReturnOrder()      (在OIOC创建退货单)

  OIOC ─POST /webhook/oioc {type:"return_complete"}─→ webhook.js
    → sync.handleReturnComplete()
      → youzan.addStock()             (有赞恢复库存)

失败处理:
  任意流程失败 ──→ retryQueue.enqueue()
    → 每15秒轮询 → 30s/60s/120s 指数退避重试 → 最多3次
```

## 四、API 参考

### 4.1 Webhook 端点

| 方法 | 路径 | 说明 | 签名验证 |
|------|------|------|---------|
| POST | `/webhook/youzan` | 接收有赞事件推送 | ✅ HMAC-SHA256 |
| POST | `/webhook/oioc` | 接收 OIOC 事件推送 | ✅ HMAC-SHA256 |
| GET | `/health` | 健康检查 | 无 |

#### 有赞事件类型

| type | 处理函数 | 说明 |
|------|---------|------|
| `trade_TradeCreated` | `handleOrderCreated()` | 订单创建 |
| `trade_TradePaid` | `handleOrderCreated()` | 订单付款 |
| `trade_TradeRefundCreated` | `handleRefund()` | 退货申请 |

#### OIOC 事件类型

| type | 处理函数 | 说明 |
|------|---------|------|
| `inbound` | `handleInbound()` | 商品入库 |
| `outbound` | `handleOutbound()` | 商品出库（发货） |
| `return_complete` | `handleReturnComplete()` | 退货完成 |

### 4.2 管理后台 API

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | 无 | 用户登录（对接OIOC账号） |
| GET | `/api/stats/summary` | operator | 获取今日统计数据 |
| GET | `/api/logs` | operator | 获取同步日志列表（支持分页/筛选） |
| GET | `/api/logs/stats` | operator | 获取日志存储统计 |
| POST | `/api/logs/cleanup` | admin | 手动触发日志清理 |
| GET | `/api/query/code/:code` | operator | 防伪码查询 |
| GET | `/api/users` | admin | 用户列表 |
| POST | `/api/users` | admin | 创建用户 |
| PUT | `/api/users/:id` | admin | 更新用户角色 |
| DELETE | `/api/users/:id` | admin | 删除用户 |
| GET | `/api/product-mappings` | admin | 产品映射列表 |
| POST | `/api/product-mappings` | admin | 创建产品映射 |
| PUT | `/api/product-mappings/:id` | admin | 更新产品映射 |
| DELETE | `/api/product-mappings/:id` | admin | 删除产品映射 |
| GET | `/api/product-mappings/search` | admin | 搜索产品映射 |
| GET | `/api/youzan/orders` | operator | 有赞订单列表 |
| GET | `/api/youzan/orders/:orderId` | operator | 有赞订单详情 |
| GET | `/api/retry-queue/stats` | admin | 重试队列统计 |

### 4.3 权限体系

| 角色 | 级别 | 权限范围 |
|------|------|---------|
| `admin` | 3 | 全部权限：用户管理、产品映射、日志清理、重试队列监控 |
| `operator` | 2 | 运营权限：查看仪表盘、日志、订单、防伪码查询 |
| `viewer` | 1 | 只读权限（保留角色） |

## 六、部署说明

### 6.1 快速启动（本地开发）

```bash
# 1. 安装依赖
npm install
cd admin && npm install && cd ..

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填入真实配置

# 3. 构建前端
npm run admin:build

# 4. 启动服务
npm start
```

访问 `http://localhost:3000`，默认管理员账号 `cangku001` / `123456`。

### 6.2 生产部署

使用 PM2 + Nginx，详见 `DEPLOYMENT.md`。

```bash
# PM2 启动
pm2 start index.js --name dirun-oioc

# Nginx 反向代理配置
# /etc/nginx/conf.d/dirun-oioc.conf
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
```

### 6.3 健康检查

```bash
curl http://localhost:3000/health
# → {"status":"ok","timestamp":"2026-04-29T..."}
```

## 七、运维指南

### 7.1 日志查看

```bash
# 应用日志
tail -f logs/app.log

# PM2 日志
pm2 logs dirun-oioc

# 同步日志（通过 API）
curl -H "Authorization: Bearer <token>" /api/logs?type=inbound&status=success
```

### 7.2 重试队列监控

```bash
curl -H "Authorization: Bearer <token>" /api/retry-queue/stats
# → {"success":true,"data":{"pending":2,"processing":0,"completed":15,"failed":1,"total":18}}
```

### 7.3 数据库维护

```bash
# 手动清理日志
curl -X POST -H "Authorization: Bearer <token>" /api/logs/cleanup \
  -H "Content-Type: application/json" \
  -d '{"daysToKeep":30,"maxLogCount":10000}'

# 备份数据库
cp database/dirun.db database/backups/dirun.db.$(date +%Y%m%d)
```

### 7.4 常见问题排查

| 问题 | 排查步骤 |
|------|---------|
| 服务无法启动 | 检查 `.env` 配置、端口占用、`npm install` 是否完整 |
| Webhook 收不到 | 确认回调 URL 可公网访问、签名密钥配置正确 |
| 同步失败 | 查看 `/api/logs` 中的错误日志、检查重试队列 `/api/retry-queue/stats` |
| 库存不一致 | 查看入库/出库日志、确认有赞商品和 OIOC 产品的映射关系 |
| 登录失败 | 确认 OIOC 第三方系统账号密码正确、有赞 Token 未过期 |
